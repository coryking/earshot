# FPGA simulations

Vivado/xsim RTL simulations take a very long time. Get Cory's express permission
before starting any run, including a single scenario, a background run, or a
cached/incremental run. This covers `scripts/run_sim.sh`, `scripts/sim_run.tcl`,
and equivalent direct simulator commands.

A general request to implement, review, test, verify, or ship does not authorize
these simulations. Neither does a reviewer's recommendation. Explain the proposed
run and its cost, then wait for Cory's explicit approval. Continue independent
work while waiting; do not make an optional simulation a delivery gate.

Cheap Python model/unit tests are outside this restriction.
